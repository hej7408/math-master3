# 수학박사 master 3.0 — 서술형 문제를 알기 쉽게 풀어가는 웹 수학교구

2019년 제66회 경기도교육자료전 수학(초등) 분야 입상작 **〈덧셈, 뺄셈 서술형 문제를 알기 쉽게 풀어가는 수학박사 master2.0〉**(연산판·조작판)을
**2022 개정 교육과정 초등 수학 1~6학년 전 영역**으로 확장한 웹앱입니다.
설치·서버·로그인 없이 브라우저에서 바로 동작합니다.

## 바로 열어 보기

- `index.html` 을 더블클릭하면 열립니다. (인터넷이 연결되어 있으면 글꼴이 예쁘게 나옵니다.)
- 학교 홈페이지·GitHub Pages·Netlify 등 **정적 호스팅**에 폴더째 올리면 그대로 배포됩니다. https 환경에서는 오프라인 캐시(PWA)도 켜집니다.
- 개발 중 확인: 이 폴더에서 `python -m http.server 5199` 후 http://localhost:5199 접속

## 요청하신 3가지 지침 반영

1. **2015 → 2022 개정 성취기준**: 교육부 고시 제2022-33호 초등 수학과 성취기준 121개를 공식 문서에서 추출해 `js/standards-data.js`에 담았습니다. 보고서에 실린 2015 성취기준 17개는 `js/standards.js`의 `MAP2015`에 2022와 대응해 두었고 [성취기준 → 2015→2022 대응표]에서 볼 수 있습니다.
2. **1~6학년 전 영역**: 59개 문제 유형(수·소재·문장을 바꿔 무한 생성)이 4개 영역에 걸쳐 121개 중 104개 성취기준과 연결됩니다. 나머지 17개는 모양 찾기·작도·분류처럼 실물 활동이 핵심이라 앱 문제 없이 ‘교실 활동으로 지도’ 안내만 표시합니다.
3. **실물 → 웹 구현**: 연산판 틀→칠판 화면, 그림카드→이모지 그림카드·수 모형, 분류카드→분류판(원작 키워드 포함), 숫자·기호 자석→자석 버튼, 보드마카→자릿값 맞춤 세로식 칸, 조작판 숫자카드→넘기는 디지털 카드, 보드게임·활동지·진단까지 모두 웹으로 옮겼습니다. 원본 보고서의 사진은 `assets/photos/` 에 있습니다.

## 문제 유형을 추가하려면

`js/problems-num.js` 또는 `js/problems-other.js` 에 `R({ id, grades, domain, std, gen(grade) { … } })` 를 추가합니다. `gen` 은 다음 항목을 돌려줍니다.

- `text` 문제 글 / `kind` 분류카드(`standards.js`의 `KINDS`) / `cards` 문제에 나오는 수(그림카드)
- `eq: { tokens: ['17','+','9'] }` 식 / `calc: { type: 'col' | 'steps' | 'units' | 'div' }` 계산 방식 / `prep` 단계별 질문
- `final: { type: 'num' | 'frac' | 'qr' | 'units', ans, unit }` 정답 / `figure` 도형·표·그래프

추가 후 `tests.html` 을 열어 `bad 0` 인지 확인하세요. 분수·소수·단위(시·분, m·cm …)는 유리수 계산기(`util.js`)로 정확히 검증됩니다.

## 알아둘 점

- 학습 기록(별, 정답률, 진단 결과)과 모험 데이터(레벨·코인·캐릭터·배지)는 **이 기기의 브라우저(localStorage)** 에만 저장됩니다. 서버로 전송하지 않습니다. (순위표는 일부러 넣지 않았어요 — 서버 없이도 쓰고, 친구와 비교하기보다 ‘어제의 나’와 겨루도록)
- 그림카드는 이모지를 사용합니다(기기에 따라 모양이 조금 다를 수 있어요). 원작처럼 직접 그린 그림을 쓰려면 `comp.js` 의 `gcard` 를 수정하세요.
- 원작 사진·마스코트의 저작권은 원작자에게 있습니다.
